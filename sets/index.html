The sets

Themed sets of ordinary web controls, each drawn a different way. Every control is a single file that defines a custom element: no dependencies, no build step, and a real control underneath.

–sets

Install any control with the shadcn CLI, or copy its file and load it with a plain script tag. Each set also ships the workflow it was made by as a skill for a coding agent, and an llms.txt. Made by Justin Finkelman, @crtvTeknologist on X.
